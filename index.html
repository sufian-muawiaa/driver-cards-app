☁️ الاتصال والمزامنة اللحظية

تربط هذا الجهاز بقناة مزامنة لحظية مع بقية الأجهزة. اختر رمز القناة وصفتك، واضغط حفظ.

⚠️ تعذر الاتصال؟ تعليمات Firestore Security Rules

لو ظهرت أخطاء "Missing or insufficient permissions" فذلك يعني أن Firestore Security Rules على الوضع المقفول (locked mode). الحل:
1. افتح Firebase Console ← مشروع saeekeen-62354 ← Firestore Database ← Rules
2. استبدل القواعد بما يلي:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /channels/{channel}/documents/{document=**} { allow read, write: if true; } } } 3. اضغط Publish ثم أعد تحميل التطبيق.
ملاحظة: هذه القواعد تسمح بالقراءة والكتابة لكل القنوات — تأمّنها لاحقًا بمصادقة المستخدمين عند الحاجة.

⚪ غير متصل — يعمل التطبيق محليًا فقط حاليًا

أول مرة تربط فيها هذا الرمز: تختار أي كلمة سر وتصير هي كلمة سر هذه القناة دائمًا. أي محاولة اتصال كـ"صاحب عمل" لاحقًا (من أي جهاز) لازم تدخل نفس الكلمة.

💰 المصروف (وقود / مصروف السائق الشخصي أثناء الرحلة)

هذا المبلغ يُصنَّف تلقائيًا "خفيف" ويُخصم من المربح العام قبل القسمة على ثلاثة.

🔧 الأعطال

خفيف يُخصم من المربح العام (مثل رقعة دولاب)  ·  ثقيل يُسجَّل بعمود مستقل ولا يُخصم (مثل عطل محرك)  ·  خطأ سائق يُخصم من نصيب السائق وحده فقط (مثل انفجار دولاب بالرصيف)
